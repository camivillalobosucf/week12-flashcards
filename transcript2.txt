● Great question! Here's the difference:

  http://localhost:5174 (Vite / npm run dev)
  - Serves only the React frontend
  - Has no idea the api/ folder exists
  - If you click "Generate Flashcards" here, the fetch to /api/generate returns
  a 404 — Vite doesn't know how to handle it

  http://localhost:3000 (Vercel / vercel dev)
  - Acts as a proxy that handles both:
    - /api/* → routes to your serverless functions in the api/ folder
    - Everything else → passes through to Vite (which it starts internally)
  - This mimics exactly what happens in production on Vercel

  So vercel dev is essentially a local simulation of the full Vercel deployment
  — frontend + backend together on one port. The npm run dev server is only
  useful for pure frontend work with no API calls.

  In short: always use localhost:3000 (vercel dev) when you need the API to
  work. Use localhost:5173/5174 only when you're doing UI-only work.
